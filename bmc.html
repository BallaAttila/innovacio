5. Business Model Canvas

Üzleti modell egy vásznon

Osterwalder-féle BMC 9 mezős változatban — minden mező a TBP-re szabva.

Kulcs partnerek

  • Merchant bankok (authorizáció)
  • Acquirer / kártyahálózatok (Visa, MC)
  • Shopify / WooCommerce app marketplace
  • Fraud / KYC adatproviderek
  • Logisztikai partnerek (visszaküldés)

Kulcs tevékenységek

  • AI Trust Scoring fejlesztés és karbantartás
  • Authorizációs flow orchestráció
  • Kereskedői onboarding & support
  • Fraud monitoring valós időben

Értékajánlat

  • Kereskedőnek: +konverzió, –refund teher, –fizetési kockázat
  • Vásárlónak: próba otthon, 0 € előre, nincs refund várakozás
  • B2B fintech: Trust API mint scoring szolgáltatás

Ügyfélkapcsolat

  • Dedikált onboarding (B2B)
  • Self-serve dashboard & analytics
  • Email + chat support
  • Negyedéves business review (top accounts)

Ügyfélszegmensek

  • Divat D2C kereskedők (€0,5–20M)
  • Shopify / WooCommerce platformon
  • CEE → EU földrajz
  • B2B Trust API ügyfelek (fintech, insurtech)

Kulcs erőforrások

  • AI Trust Scoring modell & adat
  • Fejlesztői csapat (full-stack + ML)
  • Bank- és kártyahálózati partnerségek
  • Brand & pilot referenciák

Csatornák

  • Shopify / Woo app store listings
  • Közvetlen B2B sales (pilot márkák)
  • Tartalommarketing + case studies
  • E-commerce konferenciák, partner-referral

Költségstruktúra

  • R&D: AI modell & platform fejlesztés (~60% év 1)
  • Fix OPEX: ~€3 700 / hó (infra, kis csapat, support)
  • CAC: ~€450 / kereskedő (sales + onboarding)
  • Veszteségtartalék: vállalt fizetési kockázat fedezete

Bevételi források

  • SaaS előfizetés: €149 / hó / áruház
  • Tranzakciós sikerdíj: 1,5% a megtartott rendelésekre
  • Trust API (B2B): €5 / 1000 hívás
  • Átlagos bevétel / shop / hó: €258
